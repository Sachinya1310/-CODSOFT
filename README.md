# Titanic Survival Prediction 🚢

This project focuses on predicting whether a passenger survived the Titanic disaster using machine learning techniques. It is a beginner-friendly project that demonstrates the complete data science workflow, including data preprocessing, visualization, and model building.

## 📌 Project Objective
The main objective of this project is to analyze passenger data and build a machine learning model that can predict survival based on features such as age, gender, and passenger class.

## 📂 Dataset
The Titanic dataset contains information about passengers, including:
- Passenger Class
- Gender
- Age
- Fare
- Port of Embarkation
- Survival status

## ⚙️ Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

## 🔍 Project Workflow
1. Data loading and inspection  
2. Handling missing values  
3. Encoding categorical features  
4. Exploratory Data Analysis (EDA) using graphs  
5. Model training using Logistic Regression  
6. Model evaluation using accuracy and confusion matrix  

## 📊 Exploratory Data Analysis
Some key insights from the data:
- Female passengers had a higher survival rate.
- First-class passengers were more likely to survive.
- Age and passenger class significantly influenced survival chances.

## 🤖 Machine Learning Model
A Logistic Regression model was used to predict passenger survival. The model achieved reasonable accuracy and helped in understanding how different features affect survival probability.
